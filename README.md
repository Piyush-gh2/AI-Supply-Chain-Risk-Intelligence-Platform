# 📦 AI Supply Chain Risk Intelligence Platform

## 🚀 Overview

An AI-powered enterprise platform that forecasts product demand, detects operational risks, and generates explainable supply chain insights using predictive analytics, RAG, and multi-agent architecture.

---

## 💡 Features

- Demand forecasting
- Inventory risk detection
- Explainable AI insights
- RAG-powered knowledge retrieval
- Multi-agent coordination
- Streamlit dashboard

---

## ▶️ Installation

pip install -r requirements.txt

---

## ▶️ Run Project

streamlit run app.py
